# Security Policy

## Supported Versions

Only the latest major version of this package is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this package, please do not open a public issue.

Instead, please report it privately via GitHub's **Private Vulnerability Reporting** feature. You can do this by navigating to the "Security" tab of this repository on GitHub and clicking "Report a vulnerability".

Alternatively, you can email the maintainer directly. All security vulnerabilities will be promptly addressed.
